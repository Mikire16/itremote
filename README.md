# ITRemote Web

Веб-версия приложения для удаленного управления компьютером через браузер с использованием WebRTC.

## Описание

ITRemote Web позволяет транслировать экран с одного устройства и просматривать/управлять им с другого устройства через любой современный браузер. Приложение использует технологию WebRTC для прямой передачи видеопотока между браузерами и Firebase только для сигналинга (обмена данными для установки соединения).

## Функциональность

- Трансляция экрана в реальном времени через прямое peer-to-peer соединение
- Просмотр удаленного экрана с минимальной задержкой
- Управление удаленным компьютером (мышь и клавиатура)
- Настройка качества и скорости передачи видео
- Генерация уникальных кодов подключения для безопасного соединения

## Преимущества WebRTC

- Прямая передача данных между браузерами без промежуточных серверов
- Низкая задержка передачи видео
- Шифрование трафика по умолчанию
- Автоматическая адаптация качества к скорости соединения
- Работа через NAT и брандмауэры благодаря STUN/TURN серверам

## Установка и запуск

1. Скачайте или клонируйте репозиторий
2. Создайте проект Firebase:
   - Зарегистрируйтесь на [Firebase](https://firebase.google.com/)
   - Создайте новый проект
   - Включите Realtime Database (используется только для сигналинга)
   - Скопируйте настройки конфигурации Firebase
3. Отредактируйте файл `js/config.js`, вставив данные вашего Firebase проекта
4. Загрузите файлы на GitHub Pages или запустите локально

### Запуск локально

Вы можете запустить приложение локально, используя любой HTTP-сервер. Например:

```bash
# Использование Node.js и http-server
npm install -g http-server
cd ITRemoteWeb
http-server

# Или использование Python
cd ITRemoteWeb
python -m http.server
```

## Использование

1. Открыть ITRemoteWeb в браузере
2. Выбрать режим (трансляция или управление)
3. Ввести код подключения (или использовать автоматически сгенерированный)
4. Нажать "Подключиться"
5. Для трансляции: разрешить доступ к экрану
6. Для просмотра/управления: дождаться установки WebRTC соединения

## Настройка Firebase для сигналинга

Для корректной работы приложения необходимо настроить правила безопасности в Firebase:

```json
{
  "rules": {
    "signaling": {
      "$code": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

## Настройка для GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите содержимое папки ITRemoteWeb в репозиторий
3. В настройках репозитория включите GitHub Pages, выбрав ветку main
4. Ваше приложение будет доступно по адресу https://[ваш-username].github.io/[репозиторий]/

### Примечание по работе на GitHub Pages

Если при публикации на GitHub Pages стили или скрипты не загружаются, выполните одно из следующих действий:

1. **Использование тега base (рекомендуется)**: 
   - Убедитесь, что в `<head>` вашего HTML-файла есть тег `<base href="./"/>` 
   - Это позволит браузеру правильно определить путь к ресурсам

2. **Абсолютные пути**:
   - Вы можете заменить относительные пути на абсолютные, добавив перед ними `/[имя-репозитория]`
   - Например: `href="/your-repo-name/css/styles.css"`

3. **Использование jekyll-seo-tag**:
   - Создайте файл `_config.yml` в корне проекта со следующим содержимым:
     ```yaml
     baseurl: "/your-repo-name"
     ```
   - В HTML-файлах используйте {% raw %}{{ site.baseurl }}{% endraw %} перед путями к ресурсам:
     ```html
     <link rel="stylesheet" href="{{ site.baseurl }}/css/styles.css">
     ```

Дополнительную информацию можно найти в [документации GitHub Pages](https://docs.github.com/en/pages).

## Требования

- Современный браузер с поддержкой WebRTC (Chrome, Firefox, Edge, Safari)
- Доступ к Firebase Realtime Database (только для установки соединения)

## Ограничения

- Браузеры могут ограничивать захват экрана в целях безопасности
- WebRTC требует HTTPS для работы на многих браузерах
- Для работы через сложные NAT может потребоваться TURN сервер (можно использовать платные сервисы)
- Для одновременного подключения большого количества пользователей рекомендуется использовать WebRTC SFU сервер

## Примечания по безопасности

- Весь трафик WebRTC шифруется автоматически
- Код подключения должен быть передан получателю через безопасный канал
- Firebase используется только для сигналинга, видеопоток передается напрямую
- Рекомендуется использовать HTTPS для максимальной безопасности
